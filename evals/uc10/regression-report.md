## What Caused the Improvement

1. **5–95% Trimmed Baseline + `sigma_eff` Floor (`anomalyDetector.ts`):** Eliminates historical outlier inflation so subsequent flash-sale spikes (`uc10-03`) are not masked by contaminated window variance, while `max(sigma_raw, EPS, 0.05 * |mu_trim|)` avoids division-by-zero FPs.
2. **`min_support >= 15` Gating (`uc10-06`):** Low-volume slices (e.g., 3 orders in a sparse province with 1 return = 33.3%) return `skipped_insufficient_support` before threshold evaluation, reducing normal-week false positives from 6/week to 0/week (`<= 3` gate satisfied).
3. **Recipient-Scoped Fingerprint + Write-After-Send (`fingerprint.ts`, `dispatcher.ts`, `uc10-07`):** `SHA256(recipientId|metric|dimensionKey|date|direction)` ensures same-day deduplication blocks duplicate sends to the same recipient without suppressing independent recipients, and `alert_history` is written strictly after `send_alert` succeeds.
