## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| data/.cache CSV bytes → COPY stream | Parsed publisher data becomes database rows |
| seeded faker RNG → all randomness | One seed controls the whole dataset; any leak breaks determinism claims |
| loader logs → operator console/CI | Owner credentials must never appear here |
